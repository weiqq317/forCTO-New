# 运维值班与排障手册

## 1. 快速定位
- 现象：无法接听/接通慢/无媒体/单向音频。
- 先看：Asterisk 日志（/var/log/asterisk/full）、RTPEngine 日志、CoTURN 日志。
- 指标：并发呼叫数、PPS、CPU、事件循环延迟、丢包/抖动。

## 2. 常见故障与处理
- 无媒体：检查 directmedia 是否关闭；确认 SDP 是否指向 RTPEngine；查看防火墙与 NAT 端口映射。
- 单向音频：检查内外网路由与 SNAT；确认 RTPEngine 接口 INTERFACE 设置是否正确；TURN 是否被阻断。
- 无法建立 DTLS：证书过期或指纹不匹配；时间漂移；中间人代理导致握手失败。
- 频繁重传/抖动大：网络链路拥塞；检查 QoS；对 TURN 服务器与 RTPEngine 增加带宽与 CPU。
- 注册失败：SIP 账户/密码错误；Asterisk ACL 拒绝；时钟漂移导致 nonce 失败。

## 3. 紧急回退
- 临时关闭转码：若 CPU 饱和导致质量下降，可临时仅透传兼容编解码器。
- 切换备用 TURN：主 TURN 不可用时切换到次级，通知用户影响范围。
- 降级并发：通过入站限流与队列，保护系统核心通话质量。

## 4. 事后分析
- 汇总失败原因、影响范围与恢复时间；形成行动项（增加容量、优化规则、修复漏洞）。
- 更新监控阈值与告警策略，完善 Runbook。
