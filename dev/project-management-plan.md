## 2. 项目愿景与目标

- **愿景**：构建企业级自动化语音客服平台，实现 7x24 小时智能接听，降低客服成本。
- **目标**：在 22 周内交付可运营的 SIP + WebRTC 智能客服解决方案，满足性能、安全与可用性要求。

---

## 3. 范围管理

### 3.1 项目交付物

1. SIP Node.js 客户端（含配置中心、监控接口）
2. RTPEngine & COTURN 部署方案
3. Coze WebRTC 集成模块
4. 基础监控/告警体系
5. 运维 Runbook、操作手册、测试报告

### 3.2 范围边界

- 不包含 CRM/工单系统集成（后续计划）。
- 不包含 AI 模型训练与调优（由 Coze 提供）。
- 不包含自研软交换或 PSTN 网关。

### 3.3 变更控制流程

1. 提交变更申请（PCR），描述影响范围、工期、成本。
2. 项目经理/技术负责人评估。
3. 变更控制委员会（CCB）审批。
4. 更新计划与文档，通知相关干系人。

## 7. 质量管理

- 采用 CI/CD，强制代码审查、自动化测试。
- 质量指标：单元测试覆盖率 ≥ 70%，关键功能自动化测试覆盖率 ≥ 90%。
- 实施质量门阀：未通过测试或 code review 不得合入主分支。
- 质量评审：每个里程碑结束时进行质量评审会议。

## 8. 风险管理

### 8.1 风险登记

详见 `risk-register.md`。

### 8.2 风险处理流程

1. 识别风险 → 录入登记册。
2. 评估概率与影响 → 定义等级。
3. 制定缓解与应急计划。
4. 在周会中跟踪风险状态。

## 9. 采购与外部依赖

- **Coze 服务**：合同/订阅、带宽计费、PAT 管理。
